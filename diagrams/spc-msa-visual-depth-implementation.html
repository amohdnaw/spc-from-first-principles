Guardrails

Gotchas that can ship a false pass

Each item names the layer that owns the failure. Fixing another layer would mask the symptom.

Generated page drift

level-07.html and level-04.html are outputs. Editing them alone produces a fix that disappears on the next chapter build.

Duplicated statistics

Inline JavaScript formulas can agree today and drift tomorrow. Python emits cases, answers, costs, ratios, and bands as JSON.

Vacuous media gate

A file existing proves nothing. Measure dimensions, frame rate, audio, cues, poster content, faststart order, and service manifest.

Neutral is still neutral

MSA's 10–30% band keeps its neutral tile. \"Improve\" names the next action, not a pass/fail verdict or a third traffic-light colour.

One MSA platform link

Move the existing index link. Adding a Level 4 link without removing it breaches the parent contract even if both links work.

Voice is the last mutation

Kokoro drives timing while shots change. RecorderService begins only after both browser and two-person gates pass.
