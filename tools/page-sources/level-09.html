Detection theory: memory beats points

A chart with a memory catches drift while every raw point still looks innocent.

Slow drift is the most expensive failure mode in manufacturing precisely because no single measurement ever looks alarming. Shewhart charts wait for extremes; EWMA and CUSUM charts accumulate evidence across subgroups. How much sooner? Simulated honestly — with EWMA's limits calibrated so both charts share the same false-alarm rate first.

EWMA limits start wide and tighten to ±3σλ/(2−λ)\pm 3\sigma\sqrt{\lambda/(2-\lambda)}±3σλ/(2−λ)​ as memory accumulates.

Patterns catch shifts before limits do. The Western Electric rules read the shape of the run, not just the extremes — two of three beyond 2σ on the same side, four of five beyond 1σ, eight in a row on one side.
